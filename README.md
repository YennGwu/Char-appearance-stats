# Char-appearance-stats
# 人物出场统计 · char-appearance-stats

一个**单文件、零依赖**的网页小工具：扫描小说文本、自动切分章节，统计指定角色在每一章的出场次数，并用浅色极简的动态条形图展示。
（云舸：这README也是ai写的，可以忽略，如果有兴趣的话，直接使用即可……）

## 功能

- **自动章节切分**：识别「第 X 章 / 序章 / 楔子 / 尾声 / 番外 / Chapter N」等常见标题，左侧实时预览章节与字数。
- **手动角色表**：每行一个角色，支持别名，格式为 `正式名|别名1|别名2`；匹配时长名优先，避免「语棠」抢占「林语棠」。
- **两种统计视图**
  - 分章统计：逐章查看本章的角色出场次数，可播放、上一章 / 下一章、拖动进度、倍速。
  - 全文累计：随章节推进不断累加，直观看到全书的人物分量。
- **导出**
  - PNG：当前视图 / 当前章节，2 倍分辨率。
  - GIF：整段章节动画（960 × 540），内置 GIF89a + LZW 编码器，无需第三方库。
- **新手引导**：首次打开时展示三步提示，可跳过、关闭，也可以在页脚「使用提示」重新打开。
- **浅色极简 UI**，适配桌面与窄屏，单文件离线可用。

## 快速开始

下载仓库中的 `index.html`，直接双击用浏览器打开即可（Chrome / Edge / Firefox 均可），无需安装依赖，也无需联网。

1. 点击左侧「选择 TXT」，导入小说文档（也支持直接粘贴文本）。
2. 在「角色名」中手动填写需要统计的角色，每行一个；有别名时用 `|` 分隔。
3. 点击「开始统计」，在「分章统计 / 全文累计」间切换，按需导出 PNG 或 GIF。

## 统计口径

- 角色名或别名**每出现一次**记 1 次提及。
- 同一角色的多个别名合并计数；匹配时**长名优先**，因此「林语棠」不会被重复拆成「语棠」。
- 章节标题不计入正文统计；书名、作者等极短标题页会自动忽略。
- 若角色超过 12 位，图表仅展示前 12 位，图表副标题会给出提示；统计仍按全部角色计算。

## 技术说明

- 原生 JavaScript + SVG 渲染，无 D3、无 CDN、无构建步骤。
- GIF 导出为自行实现的 GIF89a 编码器：固定调色板 + 最近色 LUT + LZW 压缩，逐帧绘制、逐帧编码。
- 文本读取支持 UTF-8（含 BOM）、UTF-16 LE/BE，并在 UTF-8 解码异常时回退 GBK。
- 章节切分与角色统计均在浏览器本地完成，文本不会上传到任何服务器。
